# 网页端中英双语实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 手机端网页支持中文 / 英文显示，始终跟随浏览器语言，页脚可临时切换（不持久化）。

**Architecture:** 引入 `vue-i18n@11`（legacy: false）。`src/locales/{zh,en}.js` 存词条，`src/logic/i18n.js` 负责检测、实例化与文档语言同步。`App.vue` 走 `useI18n()`，`ble-client.js` 与 `useBle.js` 通过导出的 `i18n.global.t()` 取词。发往电脑端日志的文本保持中文常量。

**Tech Stack:** Vue 3、vue-i18n 11、Vite、Node 内置测试。

```js
// 语言只跟随系统（浏览器语言）：中文环境用中文，其余英文。
// 手动切换只对本次会话生效，不写入 localStorage，刷新后回到系统语言。
import { createI18n } from 'vue-i18n';
import zh from '../locales/zh.js';
import en from '../locales/en.js';

function detectLocale() {
  return navigator.languages.some((lang) => lang.toLowerCase().startsWith('zh'))
    ? 'zh'
    : 'en';
}

export const i18n = createI18n({
  legacy: false,
  locale: detectLocale(),
  fallbackLocale: 'en',
  messages: { zh, en },
});

function applyDocumentLocale() {
  const locale = i18n.global.locale.value;
  document.documentElement.lang = locale === 'zh' ? 'zh-CN' : 'en';
  document.title = i18n.global.t('app.title');
}

export function setLocale(locale) {
  i18n.global.locale.value = locale;
  applyDocumentLocale();
}

applyDocumentLocale();
```

const logText = `已连接（第 ${this.#dropCount + 1} 次）`;
